Why 16AD illustrative wording

16AD is suitable on the runways it uses (dry runway): tailwind up to 0 kt, crosswind up to 12 kt.

16AD stays viable for the whole window, to 23:30Z.

Banners (current mode unsuitable, early change, no suitable mode, conditions met) appear in the state label on the main screen and are written out in full here.

Key

✓ HOLD: stay on this mode
▲ CHANGE SOON: planned change or early change advised
✕ CHANGE NOW: current mode unsuitable, or no mode fits
✓ Suitable ▲ Marginal: passes with a caution word ✕ Unsuitable ? Unknown Recommended path Dashed line: planned change Amber band: HIGH traffic White corner: depends on an uncertain input ✕ on a runway end: tailwind
